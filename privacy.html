Janus — Privacy Policy

Last updated: 2026-09-14

1. What Janus is

Janus is a personal assistant application operated for the private use of its owner.

2. Google Calendar data

When the Google Calendar integration is enabled, Janus accesses Google Calendar data using permissions granted by the user through Google OAuth.

The data is used only to provide calendar-related functionality requested by the user.

3. Data sharing

Janus does not sell Google user data and does not use Google user data for advertising. Google user data is not shared with third parties except where necessary to provide a user-requested integration or where required by law.

4. Data storage and retention

Janus is a self-managed application. Data may be stored by the Janus installation as required for its functionality. The owner of the installation controls the environment and is responsible for local data retention and deletion.

5. Revoking access

The user can revoke Janus's access through their Google Account security settings. Removing the stored OAuth credentials from the Janus installation also prevents use of those credentials.

6. Contact

For questions about this application or this privacy policy, contact the developer using the email address associated with the Janus Google Cloud project.
